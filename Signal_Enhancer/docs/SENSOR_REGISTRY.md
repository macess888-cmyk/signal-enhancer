SENSOR REGISTRY

Registered Sensors:

01 Pulse Sensor
Detects rhythm, cadence, recurrence, acceleration, and irregularity.

02 Movement Sensor
Detects directional movement, reverse movement, lateral movement, recursive movement, and hidden movement.

03 Phase Sensor
Detects state transition:
stable → forming → transition → drift → rupture → reformation

04 Invisible Drift Sensor
Detects changes that may not be visible at the object level.

05 Relationship Sensor
Detects changing relationship fields:
usefulness → trust → reliance → expectation → dependency

06 Boundary Sensor
Detects weakening or crossing of boundaries:
observation → influence → reliance → deference → authority-like standing

07 Pressure Sensor
Detects burden relocation:
human → process → automation → infrastructure → consequence

08 Consequence Horizon Sensor
Detects shrinking correction windows:
small correction → large correction → no correction available

09 Sentinel Signal Generator
Introduces harmless dummy signals to reveal hidden authority, dependency, standing, preservation, or control surfaces.

Core rule:

Sensor ≠ Authority
Detection ≠ Decision
